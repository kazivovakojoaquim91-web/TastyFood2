# TastyFood — Plataforma de Divulgação e Gestão de Pratos

## Sobre o Projeto

O **TastyFood** é uma aplicação web desenvolvida para facilitar a publicação, divulgação e gestão de pratos alimentares. A plataforma oferece uma interface moderna, intuitiva e responsiva, permitindo apresentar diferentes opções gastronómicas de forma organizada e visualmente atrativa.

O sistema permite que os utilizadores publiquem pratos, adicionem informações relevantes, disponibilizem imagens e consultem os pratos publicados. Cada publicação apresenta o nome do prato, a sua descrição, o preço em Kwanzas (Kz) e a respetiva imagem.

O TastyFood nasce da ideia de unir tecnologia e gastronomia, proporcionando uma experiência digital simples e agradável para a apresentação de produtos alimentares.

## Objetivos do Projeto

- Desenvolver uma plataforma web para divulgação de pratos alimentares.
- Facilitar a publicação e gestão de informações dos pratos.
- Proporcionar uma experiência de navegação simples e intuitiva.
- Organizar e apresentar os pratos de forma atrativa.
- Aplicar conhecimentos práticos de desenvolvimento web e gestão de bases de dados.

## Funcionalidades

- **Publicação de pratos:** permite adicionar novos pratos à plataforma.
- **Gestão de informações:** permite editar os detalhes dos pratos publicados.
- **Imagens:** possibilidade de associar imagens aos pratos.
- **Preços:** apresentação dos valores em Kwanzas (Kz).
- **Visualização dinâmica:** os cartões dos pratos são apresentados na página inicial quando existem pratos publicados.
- **Interface responsiva:** adaptação a diferentes tamanhos de ecrã.
- **Carrossel de imagens:** apresentação visual de conteúdos gastronómicos na página inicial.

## Tecnologias Utilizadas

O desenvolvimento do TastyFood envolve as seguintes tecnologias:

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação das páginas web. |
| CSS3 | Estilização e personalização da interface. |
| Tailwind CSS | Construção de layouts e componentes visuais. |
| JavaScript | Interatividade e funcionalidades dinâmicas. |
| PHP | Processamento no lado do servidor e lógica da aplicação. |
| MySQL | Armazenamento e gestão dos dados. |

## Base de Dados

O projeto utiliza MySQL para armazenar e organizar as informações necessárias ao funcionamento da plataforma, incluindo os dados dos pratos publicados.
